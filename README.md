# Nancy Joy — Web Developer Portfolio

A dark, modern portfolio website showcasing my web development work. Built with HTML5, CSS3, and Vanilla JavaScript.

**Live Site:** [nancyjoy-portfolio.vercel.app](https://nancyjoy-portfolio.vercel.app)

## About

This portfolio highlights three shipped projects:

- **ElimuCards** — Full-stack digital report card system for Kenyan schools (React, Node.js, PostgreSQL)
- **Maisha Beauty Lounge** — Responsive salon & spa booking website (HTML5, CSS3, JavaScript, Calendly, Formspree)
- **Crumble & Co.** — Artisan bakery marketing website (HTML5, CSS3, JavaScript, Unsplash API)

## Tech Stack

**Frontend:**
- HTML5, CSS3, Vanilla JavaScript
- Responsive design
- Intersection Observer for scroll animations

**Tools & Services:**
- Vercel (deployment)
- Git & GitHub
